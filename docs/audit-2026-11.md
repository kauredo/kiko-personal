# November 2026 audit record

## Summary

A one-page site for a musician, built with Vite, React and Convex. The site is dormant. The audit found it technically clean and correctly tagged, with one serious backend hole (a public mutation that created admin accounts), which is fixed and deployed. Everything else is vanity-site growth work that the audit judged not worth doing while the site is dormant.

## Shipped from the audit

- Admin creation and the seed mutations became internal, and the analytics tag loads only when configured (#19).
- Contact form caps and a honeypot, the analytics beacon limited to real routes, and an admin login lockout (#22). The Convex backend was deployed for both changes.
- Autocomplete tokens on the contact form and the admin login (#19).
- `CLAUDE.md` no longer says `convex/_generated/` is gitignored. It is tracked because Vercel builds need it.
- Production check on 2026-11-15: the `users` table held one row, the seeded admin, and no other admin existed.

## Open work

None. Nothing is left that needs a plan.

## Waiting on

- Change the seeded admin's password. The seed still creates the admin with a default password, and the owner has to set a new one in production. This is a manual step in the running backend.
- A custom domain: the canonical URL, Open Graph tags, JSON-LD, sitemap and `llms.txt` all use the `vercel.app` host, so a move rewrites about 10 URLs. Waits for the musician to say he wants to promote the site. If he does not, there is nothing to do.

## Decide

Nothing open.

## Won't do, and why

- Purge expired sessions, or allow more than one session per user: one admin, tiny table.
- Bound the `.collect()` calls on public queries: the report itself said no action needed.
- Move the render-blocking Google Fonts stylesheet: dormant, no users to benefit.
- Tests and CI (Dependabot PRs unbuilt): dormant, payoff too small. The report's idea was vitest with `convex-test` and three tests: admin mutations throw without a token, `createAdmin` is absent from the public `api`, and the contact limits hold.
- Server-render the single-route shell (empty `#root`, `/nonexistent` returns 200, no `lastmod`): a name-search vanity site only needs to load, and the static head is already right.
- Fix possible theme-name drift in `CLAUDE.md`: low confidence, low value.
- Replace Lenis smooth scroll with native CSS: it is the art direction. Raise it only when touching it, and there is no platform equivalent for wheel smoothing.
- `<dialog>` or `popover` for the mobile menu and gallery: low priority, and framer-motion stays anyway.
- Answer the search questions "where has he played", "how do I book him", "where can I hear his music" and "upcoming gigs" in static HTML: dormant site. The contact form needs JavaScript and the credits live in Convex text, not in the HTML. Revisit only if the site gets promoted.
